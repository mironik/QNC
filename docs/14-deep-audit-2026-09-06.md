## Zakljucak

Postoji modularna osnova, ali jos ne postoji funkcionalno dovrsen Ingest.
Najvazniji blokator nastavka nije novi UI: treba dovrsiti javni ugovor radnih
postavki, citanje samostalne baze, stabilan identitet izvora i stvarni pristup
podacima preko transporta. Tek tada dodavati scanner/probe/import.

Nisam nasao aktivnu poslovnu vezu Ingest -> Project preko cratea, API-ja ili
shared workflow servisa. Nedostaje upravo dopustena veza: citanje dogovorenih
podataka iz baze. Ne treba uvoditi aplikacijski bridge da bi se taj nedostatak
rijesio.

### F1 - P1: Baza projekta jos nije dovoljan javni ulaz za Ingest

Pravila: AGENTS 3, 4, 5.

Project stvarno sprema postavke u `project_settings.settings_json`. Medjutim,
`public_project_settings` objavljuje samo `project_id`, `template_id`,
`created_at`, `updated_at`. Javni snapshot/workflow pogledi takodjer ne daju

Oznaka `active_project_id` sprema se u globalni `app_settings`, ne u svaku
projektnu bazu. `active_step_id` u projektnoj bazi je workflow korak, a ne oznaka
aktivnog projekta. Kopirana pojedinacna baza zato nema trazeni samodostatni
javni zapis aktivacije i postavki.

Ingest nema read-only reader tog ugovora, njegov manifest ima prazan
`read_database_contracts`, a komponenta otvara samo vlastite Ingest baze.
Trenutni source-select radi bez provjere aktivnih radnih postavki. To je
nedostajuci preduvjet prije razvoja media rada, ne preporuka povezivanja aplikacija.

### F3 - P1: Identitet kartice i trajnost source URI-ja nisu pouzdani

Pravila: AGENTS 1, 5, 7, 9.

`card_id` ukljucuje serijski broj, naziv volumena i vrstu izvora. Promjena naziva
istog volumena zato stvara drugi identitet kartice. Reproducirano s istim
serijskim brojem i dva naziva. To ce narusiti buduce prepoznavanje vec ucitanih
klipova; duplicirani import jos nije mogao nastati jer import nije implementiran.

Browser URI je hash lokalne putanje, a mapa URI -> putanja zivi u memoriji
browser sesije. Nova sesija ne moze otvoriti ranije dobiven URI bez ponovnog
uspostavljanja bindinga. Ingest zapisuje privatni binding, ali nema njegove
ponovne upotrebe u novoj browser/resolver sesiji. Reprodukcija: URI koji je
browser izdao ne otvara se u novoj sesiji; obicni resolver ga pretvara u drugu,
nepostojecu putanju pod svojim rootom.

Normalizacija uvijek radi `to_lowercase()`. Na case-sensitive filesystemu dvije
razlicite putanje razlikovane velikim/malim slovom postaju isti URI; `or_insert`
zadrzava prvu. To je nalaz iz koda, ne Linux live reprodukcija.

Windows koristi filesystem volume serial iz `GetVolumeInformationW`, ne
hardverski serijski broj SD kartice. Za non-Windows root list vraca samo `/`,
bez inventara volumena, serijskog broja i naziva.

## Tocno tumacenje pravila i starih nalaza

- Shell adapter smije tranzitivno koristiti desktop/component/store iste app
  prema trenutnom AGENTS 16. Sam taj dependency nije novi dokaz zabranjenog
  monolita. To je odobren privremeni in-process model, ne procesna izolacija.
- Shell nema poslovnu bazu; Ingest nema Project crate dependency.
- `qnc-ui-kit` ostaje uzak pasivni modul; nema poslovni registry, browser
  session ownership, DB ni media workflow.
- Project stvara globalnu i pojedinacne projektne baze. System template guard
  i user template brisanje imaju testove.
- Busy timeout/WAL konfiguracija postoji; tvrdnja da concurrency uopce nije
  razmatran vise ne vrijedi. Dugi UI/I/O i delete transakcije ipak ostaju rizik.
- Workspace status od 22 px jest naveden kao odstupanje u docs/10. Stari nalaz
  da zapis ne postoji vise ne vrijedi.
- Nije nadjen izvrsni naknadni ffprobe u novom Project/Ingest runtimeu.
  Zabrana jos nije dokazana za buduce media module jer oni ne postoje.

Dokumentacija zaostaje: docs/12 jos predlaze Project registry/workspace ulaz
umjesto novog pravila samostalne projektne baze; docs/13 pri dnu tvrdi da nema
Ingest crateova iako ih pocetak dokumenta opisuje; docs/10 jos kaze da registry
prikazuje samo Project. Potrebno ih je uskladiti s AGENTS, ne slabiti AGENTS da
bi opis odgovarao kodu.

`SQLITE_OPEN_READ_ONLY`.

Nije izvrseno: novi native GUI live/pixel/fokus test prema v4, stvarni LAN ili
Intranet endpoint, Linux/macOS/ARM run, puni import/probe/player/filmstrip/wave,
prekinuti proces tijekom brisanja, niti multi-process stress nad korisnickim
bazama. Nije pokrenut ffprobe/ffmpeg. Nema upisa na karticu.

## Predlozeni nastavak

1. **Zakljucati ulazni DB ugovor radnih postavki.** Definirati javni zapis
   aktivacije, verziju i payload te ponasanje za 0/vise/nevaljanih baza.
   Za promjenu Project writer/schema/view dijela traziti ciljanu dozvolu prema
   freeze pravilu. Ne dirati Project UI ni druge postavke. Nema migracije.
2. **Dovrsiti neutralni DB reader i transport pristup.** Samostalni Ingest
   cita danu bazu read-only bez Projecta i shella. Test mora raditi na drugoj
   lokaciji izvan repozitorija, uz definirane local/LAN/Intranet endpointe.
   DB transport nije servis za suradnju aplikacija.
3. **Stabilizirati izvore i pozadinski browser rad.** Ispraviti identitet,
   trajne bindings i OS adaptere; prebaciti I/O iz UI threada. Uzak zajednicki
   browser prikaz bez confirm/cancel gumba; gumbe i dalje crta UI kit.
4. **Implementirati Select u javnim modulima.** Scanner i camera detector
   utvrdjuju original/proxy uloge. Jedini media probe prolaz sprema sve
   ugovorene original/proxy podatke. Ingest komponenta koordinira samo vlastiti
   workflow. UI pasivno prikazuje rezultate iz baze, bez probe fallbacka.
5. **Zasebno provjeriti odabir klipova i import.** Kontrolirati sto se uvozi,
   gdje je odredisni URI, sto se zapisuje i kako se prijavljuje prekid/greska.
   Stvarna kartica ostaje read-only; razvojni output ide na dogovoreni endpoint.
6. **Tek potom filmstrip/wave i ostali potrosaci.** Ulaz su vec zapisani media
   podaci. Filmstrip: proxy ako postoji, inace original; 14 stvarnih frameova;
   bez probea. Batch zavrsetak gasi rad; ne ostavlja Ingest servis drugim appovima.

Svaki korak mora imati izvrsni pozitivan/negativan contract test i odgovarajuci
live test. Prioritet prije dodatnog UI ili media koda: dokazati da sama baza
zaista daje Ingestu radne postavke, bez ikakve prisutnosti Project aplikacije.
