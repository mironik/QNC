## Zakljucak

Od zadnjeg audita (docs/22) radno stablo je preslo iz "browser + registry zapis"
u stvarni Select: scan, original/proxy grouping, source-index, jedan probe
prolaz i media-records. To je vec implementirano u
`qnc-ingest-components/src/selection.rs` kada postoji
`data/ingest-transport.json`.

To jos nije puni Ingest. `Uvezi` je odbijen. `ingest_content` (`clips`,
`probe_records`) ostaje prazna shema. Filmstrip, Wave i Broadcast Player
imaju samo ugovore. Kasniji moduli nemaju javni Ingest clip katalog koji
mogu citati bez poznavanja Select radne memorije.

Nisam nasao Ingest -> Project crate/API vezu niti app-to-app bridge.
Project freeze nije narusen. Granice modula (ffprobe samo u `qnc-media-probe`,
bez liste dozvoljenih aplikacija) drze se.

Najvazniji blokator nastavka nije novi media modul. Treba zatvoriti proizvod
Selecta u javni DB ugovor (`ingest_content` ili dogovoreni citacki sloj nad
`media_records`) i tek onda import / filmstrip / wave / player.

## Select call chain

```text
Odaberi (INGEST_DIR_CONFIRM)
  -> load_work_settings (read-only)
  -> confirm_source_selection
       -> IngestStore::record_source_selection   (ingest_registry)
       -> selection::run
            -> SourceReader
            -> camera-patterns.read_uri
            -> scanner.scan_roles  (-> camera-detector)
            -> source-index-db.write
            -> sony-metadata + thumbnail (source-reader + image-assets)
            -> media-record-db Camera
            -> media-probe (acquisition claim, jedan pokusaj)
            -> ffprobe-metadata.read
            -> media-metadata-compose + media-record-db Final
            -> Event::Clip u IngestViewModel (memorija)
```

Bez `transport_browser` (nema valjanog `ingest-transport.json`) Odaberi
odbija izvor. U repozitoriju nema primjera te datoteke. Binding je
deployment, ne radna postavka projekta (`docs/34`).

## Prioritetni nalazi

P1 = blokator sljedeceg razvojnog koraka ili ugovorna rupa koju kasniji
moduli ne mogu zaobici. P2 = vazan nedostatak s manjim neposrednim dosegom.
P3 = dokumentacija / conformance / redoslijed.

### F1 - P1: Javni Ingest clip/probe katalog nije napunjen

Pravila: AGENTS 4, 5, 6.

Select pise `source_index` i `media_records`. `qnc-ingest-store` kreira
`clips`, `clip_sources`, `clip_proxy` i `probe_records`, ali nema metode
koja ih puni. View klipova zivi u komponenti i gubi se na reload.

Filmstrip, Wave i Player po zakonu citaju samo bazu. Danas nemaju sto
citati iz `ingest_content`. `media_records` je vlasnicka Ingest baza, ali
nije ugovoreni clip katalog za kasnije aplikacije.

Dokazi:
`crates/qnc-ingest-components/src/selection.rs` (source-index i media-record
write), `crates/qnc-ingest-store/src/lib.rs` (shema bez INSERT-a),
`contracts/applications/ingest.application.json` (owned `ingest_content`).

### F2 - P1: Uvezi nije implementiran

`INGEST_IMPORT_SELECTED` vraca "Media import jos nije implementiran."
Radni plan i dalje racuna original/proxy/audio/incoming/thumbnail URI-je.
Nema potrosaca koji kopira medij ili pise import operaciju.
`ClipView.imported` ostaje `false`.

To je poznat sljedeci korak, ne regresija. Select nije import.

### F3 - P1: Select ovisi o privatnom transport bindingu izvan repozitorija

Bez `data/ingest-transport.json` (ili `QNC_INGEST_TRANSPORT_CONFIG`)
komponenta pada na stari Dir Browser. LAN/Internet tada ostaju poruke
"nije povezan". Odaberi zahtijeva `transport_browser.selected(uri)`.

Isti SourceReader API postoji za local i remote. Remote zahtijeva
eksplicitni endpoint i credential. Nema inferencije URL-a iz UI teksta.
Zivi LAN/Intranet host nije verificiran u ovom auditu.

### F4 - P2: AGENTS §16 i docs/01 vise ne opisuju kod

§16 i dalje kaze da je Ingest samo browser + registry i da scanner/probe
ne smiju biti u runtime manifestu. Manifest ih ima i Select ih koristi.
docs/01 kaze da source-index i media-records nisu spojeni na Odaberi.
docs/21/32/33 imaju iste zastarjele recenice.

Pravila u §1-15 i dalje vrijede. Zastarjela je samo lista odstupanja.

### F5 - P2: `image-assets` koristi se, ali nije u Ingest manifestu

`qnc-ingest-components` zove `decode_thumbnail`.
`contracts/modules/image-assets.module.json` postoji.
`ingest.application.json` `module_dependencies` to ne nabraja.
Conformance to ne hvata jer usporeduje samo deklarirano prema crateovima,
ne obrnuto.

`media-metadata` je u manifestu, a u komponenti se ne importira izravno
(samo preko compose).

### F6 - P2: Thumbnails nisu trajni

docs/35 je ispunjen za worker + pasivni paint + bez novog probea.
`thumb_image` je `#[serde(skip)]`. Reload gubi sliku.
`INGEST_APPROVE_PROXY_POSTERS` nije spojen.
To nije filmstrip.

### F7 - P2: Sitni ugovorni driftovi u modulima

- `qnc-source-reader` `VERSION = "0.3.0"`, contract `0.2.0`.
- `qnc-media-records` nema vlastite unit testove.
- Cetiri contract sloja nisu u conformance `runtime_crate` mapi
  (`source-contract`, `source-index-contract`, `json-transport`,
  `media-records`) - nisu u Ingest `module_dependencies`, pa alat prolazi.

### F8 - P3: Media Assist / Story i media UI moduli nisu krenuli

Tocno po redoslijedu (AGENTS 13): prvo baza koju moduli citaju.
Nema crateova, nema app registryja. Shell footer i dalje samo Project i Ingest.

## Granice koje drze

- Nema `qnc-project*` ovisnosti u Ingest crateovima.
- Work settings: `query_only`, bez INSERT/UPDATE u produkciji.
- Moduli nemaju `allowed_applications`; `qnc-contracts` to odbija.
- Produkcijski `Command::new` za ffprobe je samo u `qnc-media-probe`.
- Acquisition ledger + Select ne retryaju failed/uncertain pokusaj.
- Proxy nije zaseban clip: grouping ide kroz source-groups; UI kartica je
  original.
- Forma ne zove scanner/probe; salje `action_id`.
- Project freeze scope prazan u `git status`.

## Dualni browser (vazno za live)

Ako se ucita transport config, `browse_registered` sluzi Local/LAN/Internet
istim SourceReader korijenima (`docs/34`).

Ako se config ne ucita, stari `DirectoryBrowserSession` radi samo Local;
LAN/Internet ostaju placeholder stringovi u `lib.rs`.

To nije dva ugovora. To je feature-gate na deployment datoteku.
